## 🪦 **Affetti**

**Software gestionale per la gestione dei cimiteri**
*Sviluppato da **piTTySoft srl***

**Affetti** è un'applicazione web pensata per la gestione completa dei servizi cimiteriali e delle pratiche connesse ai cari scomparsi.

### ✨ Funzionalità principali:

* **Gestione delle domande di sepoltura**
* **Creazione e gestione dei contratti** (loculi, tombe, ossari, ecc.)
* **Assegnazione e tracciamento delle sepolture disponibili**
* **Gestione delle concessioni cimiteriali**
* **Storico delle pratiche e dei contratti**
* **Ricerca e visualizzazione dei defunti**
* **Integrazione tra frontend Angular e backend Java (Spring Boot)**

### 🏗️ Architettura tecnica:

* **Frontend**: Angular 16 con Bootstrap 5 e NgRx
* **Backend**: Java 17 con Spring Boot
* **Persistenza**: JPA + database relazionale
* **Deploy**: compatibile con ambienti on-premise e cloud
