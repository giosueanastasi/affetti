# Guida Utente non autenticato

> **Stato:** In fase di sviluppo

## Descrizione ruolo

L'utente non autenticato rappresenta un visitatore anonimo del sistema. Ha accesso esclusivamente alle funzionalita' pubbliche.

## Funzionalita' disponibili

- Ricerca defunti tramite la pagina pubblica "Cerca Defunti"
- Visualizzazione dettaglio singolo defunto (scheda con dati anagrafici, elogio funebre, mappa)
- Registrazione di un nuovo account (assegna automaticamente il ruolo USER)
- Login
- Consultazione privacy policy e termini e condizioni

## Aree accessibili

| Sezione | Accesso |
|---|---|
| Home | Si |
| Cerca Defunti | Si |
| Dettaglio defunto | Si |
| Login | Si |
| Registrazione | Si |
| Privacy Policy | Si |
| Termini e Condizioni | Si |
| Tutte le altre sezioni | No |

## Limitazioni

- Nessun accesso alle aree riservate del sistema
- Non puo' visualizzare dashboard tenant, anagrafiche o sezioni operative
- Per accedere a funzionalita' aggiuntive e' necessario registrarsi e autenticarsi
