# Guida USER

> **Stato:** In fase di sviluppo

## Descrizione ruolo

Lo USER e' l'utente base del sistema, tipicamente assegnato in automatico dopo la registrazione self-service. Ha accesso limitato alle funzionalita' di consultazione.

Non e' associato a nessun tenant specifico.

## Funzionalita' disponibili

- Ricerca defunti pubblica e visualizzazione dettaglio
- Consultazione lista domande e contratti
- Ricerca contratti
- Consultazione CAP e comuni
- Gestione profilo personale (password, email)

## Aree accessibili

| Sezione | Accesso |
|---|---|
| Home | Si |
| Dashboard tenant | No |
| Domande (consultazione lista) | Si |
| Contratti (consultazione) | Si |
| Contraenti | No |
| Posti | No |
| Assegnatari | No |
| Utenti | No |
| Admin | No |
| Cerca Defunti | Si |
| Profilo | Si |

## Limitazioni

- Nessuna visibilita' sui tenant e relative dashboard
- Non puo' accedere alle anagrafiche operative (contraenti, posti, assegnatari, utenti)
- Non puo' creare o modificare alcuna entita'
- Possibilita' di modifica limitata al contesto della ricerca defunti
